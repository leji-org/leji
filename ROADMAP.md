# Roadmap

## What this is

A direction, not a schedule. This file names the open themes the steward accepts feature requests toward, and the questions it holds open. It carries no dates.

A theme's presence means requests toward it are welcome. A request that falls outside every theme makes the case for a new one, through the feature-request path in [Before you build](CONTRIBUTING.md#before-you-build).

## Standing direction

The 1.0 specification line is frozen: clarifications and additive schema changes only. Anything incompatible is a new line.

The reference packages release together, and they only move forward.

Conformance never requires a product or a service. Local stays the default.

## Open themes

- **Search over the specification.** On leji.org, with in-page contents for the long pages.
- **A second independent implementation.** The steward welcomes one. The shared fixture suite is what checks compatibility across implementations, and the steward answers an implementer's questions about it in public and reviews a conformance claim when asked.
- **An adopters page on leji.org.** Seeded with this repository as one adopter among many.
- **In-process actors.** A candidate for the specification's next line, in the manifest's actor registry. Today an actor must declare commands, so the running session cannot be declared.
- **Record streams.** An additive mechanism after the GA freeze.

## Parked questions

Whether a non-git hosted profile should ever exist.

A parked question invites evidence and discussion, not implementation. Nothing is built toward it until the steward records a direction.

## How to move a theme

A theme moves by feature request, the path described in [Before you build](CONTRIBUTING.md#before-you-build). A proposal that changes the specification itself follows [How the specification changes](GOVERNANCE.md#how-the-specification-changes).

Where a steward-authored proposal touches an area a steward product depends on, [the conflict rule](GOVERNANCE.md#steward-proposals-and-conflicts-of-interest) applies as written there.
