# Templates

Copyable starters: manifest (leji.json), boot profile (boot-profile.md), core agent profile, role profile, decision record, and the solo-mode starters `identity.md` (domain: who is behind the work, audience, positioning, claim boundaries) and `writing-style.md` (practice: voice, tone by channel, formatting rules, patterns to avoid). Copy, fill in the placeholders, delete what you don't need. See adoption/README.md for the order. `leji init --mode solo` scaffolds the two solo starters automatically.

Naming: Leji-owned files use lowercase-kebab (`docs/boot-profile.md`, `agents/core.md`); ecosystem-fixed entrypoints (`README.md`, `CLAUDE.md`, `AGENTS.md`) keep their required names.
