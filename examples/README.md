# Examples

Two deliberately boring reference context layers: monorepo/ (single repo at `indexed` conformance, the level that adds a generated index and a machine-readable changelog on top of `core`, fully materialized and schema-valid) and multi-repo/ (a `federated` setup, the top level, where a layer declares pinned mounts of other teams' layers: dedicated context repo, docs-only submodule consumers, a sibling mount).

The four levels and what each asks of a team are in [the conformance checklist](../spec/conformance.md).
